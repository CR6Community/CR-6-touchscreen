# CR-6 Touchscreen firmware for CR6_CF_as_Marlin-2.0.9.x_extui

## Where is CR6_CF_as_Marlin-2.0.9.x_extui?
Until the mainboard firmware is completed and stable, that repository remains private and unavailable.

There is no specific target date for completing the mainboard firmware upgrade, but Thinkersbluff does hope to have something ready to offer for evaluation, before the end of 2025.

## Why do we need a new UI firmware for CR6_CF_as_Marlin-2.0.9.x_extui?
1. Because Marlin changed some of the functionality on which the 6.1.x version of the UI depended.  It became necessary to modify some screens and introduce others, to hide or replace the deprecated functions.
2. Because Marlin has introduced new features at 2.0.9.x, which users may wish to access from the display. (e.g. MPC, Input Shaping, PTC, etc.)
